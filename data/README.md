yoktur; isimler, rakamlar ve politikalar bu proje için uydurulmuştur.

  doğru cevabını model ancak bizim dokümanlarımızdan bulabilir. Böylece doğru cevap gelirse
  bunun retrieval sayesinde olduğundan emin oluruz.

  geçtiğini kesin olarak işaretleyebiliriz.
